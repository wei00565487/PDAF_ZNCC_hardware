# 未検証事項と次にやること

## 要約

**確定していないことを確定したことにしないための一覧。**
最大の宿題は FDTD による DTI 反射とグリッド導波の検証。次が CFA 実測データの投入。

## 優先度 1 — FDTD の決着

- [ ] 解像度 60 の 3 本（グリッド有 r45 / r60、グリッド無 r60）を完走させる（2026-09-08 実行中）
- [ ] BPM 値と突き合わせ、**酸化膜 DTI の反射**がどれだけ QE を戻すかを確定
- [ ] **低屈折率グリッドで QE が上がる**という結論を FDTD で確認（BPM の導波計算依存）
- [ ] 混色率が解像度 60 → 80 で収束しているか（30→45 で 27% 動いた前科あり）

これが決まるまで、[[30-results]] の QE 絶対値は「吸収壁モデルの下限」として扱うこと。

## 優先度 2 — 入力データの実測化

- [ ] **CFA 厚の実測値**。混色絶対値の最大の不確かさ（0.90µm は根拠なし）
- [ ] **CFA 透過カーブの実測**。色純度・CCM 利得の数値はこれに完全依存
- [ ] K 画素（IR パス黒レジスト）のカーブ、特にカットオン波長
- [ ] オンチップ IRCF の実 OD。G 画素間 IR ばらつきの下限を決める
- [ ] Si の n, α をベンダーデータに差し替え（`materials.load_si_csv`）

## 優先度 3 — モデルの拡張

- [ ] **オンチップ IRCF の斜入射カットオンシフト**。干渉膜なら F/1.8 周辺光線 16° +
      CRA 30° = 46° で数十 nm 短波長シフトする。650-800nm 遷移帯の数値が変わる
- [ ] IRCF の横方向屈折率段差（R/G/B 上 1.65 vs K 上 1.46、OPD 約 λ/10）
- [ ] メタルグリッド（W-grid）
- [ ] マイクロレンズのセル境界の扱い（現状は尖りが残り相対 0.6% の散乱損失）
- [ ] レイアウト起因の Gr/Gb 差（現状は全画素同一幾何）

## 優先度 4 — 検証の拡張

- [ ] 実測 QE カーブとの突き合わせ（現状、絶対値を実機と比較していない）
- [ ] 実測 Gr/Gb アンバランスとの突き合わせ。像高 0 の残差からレイアウト成分を切り分ける
- [ ] 混色測定（スポットスキャン）との比較

## 既知の限界（対処しないと決めたもの）

- スカラー BPM なので偏光依存とベクトル集光効果は扱えない → 必要なら FDTD
- 一方向 BPM なのでスタック内の多重反射は扱えない → 同上
- マイクロレンズ境界の尖りによる相対 0.6% の系統誤差は受け入れる
