# 物理モデル — BPM・随伴拡散・F 値光束

## 要約

裏面照射（BSI）画素を、**角スペクトル法 BPM で Si 内生成率分布 `G(x,y,z)` を作り、
拡散方程式の随伴解 `u(x,y,z)` と内積を取る**という 2 段構成で解く。
随伴法により、幾何が同じなら線形ソルブ 1 回で全条件のカーネルが得られる。

## 1. 光伝搬（`bxsim/optics.py`）

層順（上から）: 空気 → マイクロレンズ → 平坦化膜 → **オンチップ IRCF** → CFA → 平坦化膜 → ARC → Si。
各層を角スペクトル法で面から面へ伝搬させる。光線追跡ではなく回折計算なので、サブミクロン
画素のようにマイクロレンズの f/# が小さい領域でも成立する。

```
kz = sqrt((2*pi*n_complex/lambda)^2 - kx^2 - ky^2)   # 減衰する分枝を選択
U(z+dz) = IFFT( FFT(U) * exp(i*kz*dz) )
```

- **マイクロレンズ**: 球面キャップの薄膜位相素子。物理量である**サグ量** `ml_sag_um` で指定し、
  曲率半径 `R = (a^2 + h^2) / 2h`（`a` = 画素の半対角）を導出する。
  レンズ上は空気なので位相差は `k0 * (n_ml - 1) * sag`。
  3.0µm 画素・サグ 0.80µm では **f = 7.82µm** に対しスタック高が 1.20µm と大幅な
  アンダーフォーカスになる。これは実際の大画素で起きていることそのもの。
  なお球面キャップをセルで切り取るため、セル境界に尖りが残る（→ [[21-validation]] の系統誤差）。
- **CFA 開口マスク**が「その光子はどのセルを通ったか」を定義する。混色の帰属は
  「**光子はちょうど 1 つの CFA セルを通る**」という厳密な分解に基づき、中心セルだけを
  開口させて計算する。周期配列なので全セル分の和が全体になる。
- **低屈折率グリッド**（`cfa_grid_enabled`）は吸収壁ではなく**横方向屈折率分布**として、
  CFA 層をスプリットステップ BPM で刻んで扱う。位相スクリーンはユニタリなのでエネルギーは
  原理的に保存する。Δn = 1.55 - 1.25 = 0.30 と穏やかなので BPM の適用範囲内であり、
  導波による閉じ込めを正しく再現できる。側壁は 50nm で滑らかにしてある
  （完全に鋭い段差はエバネッセント次数に電力を捨てるため）。
- **DTI** は BPM 上では**吸収壁**（振幅マスク）。実際の酸化膜 DTI は光を反射して自画素に
  戻すので QE を過小評価する。Δn ≈ 2.6 と大きく、後方反射が本質なので BPM では扱えない
  （→ [[50-fdtd-meep]]）。
- **ARC** は 1 層特性行列法で s/p 平均の斜入射透過率まで計算する。550nm・垂直入射で
  T = 0.9608（ARC 無しのベア Si なら 0.68）、45° で 0.9462。

### 吸収の計上（重要な実装上の注意）

各スラブの吸収を `alpha * |E|^2` で計上すると、**斜め成分を過小評価する**。角スペクトル
伝搬では斜め成分の場が `alpha / cos(theta)` で減衰する（光路が `dz / cos(theta)` だから）のに、
計上側が `alpha` 固定だと収支が合わない。マイクロレンズで角度がつくと約 1% ずれる。

現在の実装は、**伝搬で実際に失われた電力をスラブごとに実測し、局所強度比で分配する**:

```
A_k(x,y) = |U_k(x,y)|^2 * (P_k - P_{k+1}) / sum(|U_k|^2)
```

伝搬は吸収以外ユニタリなので、これは総量が厳密で分布も物理的に妥当。

## 2. キャリア輸送（`bxsim/diffusion.py`）— 随伴法

少数キャリアの定常方程式

```
D grad^2 n - n/tau + G = 0,   n = 0（PD 空乏層内）,  D dn/dnu + S n = 0（再結合面）
```

に対し、随伴場 `u` を

```
D grad^2 u - u/tau = 0,   u = 1（対象 PD 内）, u = 0（他の PD 内）,  D du/dnu + S u = 0
```

と定義すると、Green の恒等式から**厳密に** `J_c = ∫ G * u_c dV` が成り立つ。
つまり `u(x,y,z)` は「その点で生成したキャリアが対象 PD に収集される確率」そのもの。
配列は周期的なので他の PD の `u` は横方向シフト（`np.roll`）で得られる。

導出（Green の恒等式、`L = D grad^2 - 1/tau`）:

```
∫(u*Ln - n*Lu)dV = D∮(u*dn/dnu - n*du/dnu)dS
Ln = -G, Lu = 0 なので  -∫G*u dV = D∮(...)dS
PD 面: n=0, u=1 → -J_c
再結合面: u(-Sn) - n(-Su) = 0 → 消える
ゼロフラックス面: 両項ゼロ
→ J_c = ∫ G*u dV
```

有限体積法 + 対称行列 + 共役勾配法（Jacobi 前処理）。

**PD は点接触ではなく体積（空乏層）としてモデル化**している（`pd_depth_um`）。
これが本質的で、DTI 深さが空乏層に届くかどうかで電気クロストークが劇的に変わる
（→ [[30-results]]）。当初 PD を前面の点接触にしていたときは電気クロストークが 66% と
非物理的な値になった。

## 3. F 値光束（`optics.generation_cone`）

センサは平面波を見ることはない。f/N レンズは半角 `asin(1/2N)` の錐を届ける
（f/1.8 なら NA = 0.278、**16.1°**）。

フラットフィールドでは射出瞳が非干渉な拡張光源として振る舞う（van Cittert–Zernike）ので、
**各方向の平面波を独立に走らせて強度を加算する**のが正しい扱い。点光源の PSF を見る場合は
瞳がコヒーレントなので場を加算する必要があり、この関数は使えない。

重みは方向余弦平面 (u,v) 上で**等重み**になる:

```
一様輝度の瞳から届く電力 ∝ L * cos(theta) * dOmega = L * du * dv
```

Fibonacci（sunflower）格子で円盤を等重みサンプリング。CRA がある場合は円盤の中心を
`(sin(CRA), 0)` にずらす。

- **検証**: F/1000 は平面波と 4 桁一致。F/1.8 は n=16 サンプルで収束
  （混色 2.613% / n=64 で 2.610%）。
- **副次効果**: 単一平面波はコヒーレント干渉で像高に対し非単調な偽構造を出す
  （0.8µm で 9.83 → 9.13 → 9.40 → 16.27%）。F 値光束にすると平均化されて単調になる
  （9.06 → 9.23 → 11.66 → 20.58%）。**平面波スイープの細かい凹凸は信用しないこと。**
