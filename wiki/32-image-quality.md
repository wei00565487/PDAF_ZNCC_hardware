# Gr/Gb アンバランスと画質影響 — どこまで深刻か

## 要約

RGB-IR の 6 個の G 画素の感度差は**新規の問題ではなく、通常 Bayer の Gr/Gb アンバランス
（緑不均一、maze / labyrinth アーティファクト）と同じ物理**。RGB-IR は 1.5 倍悪いだけ。

画質影響は**軸上では無害、像高では有害**。相対 % は信号が小さいから大きく見えるだけだが、
**ΔG の絶対値はシーンの分光にほぼ依らず R 信号に比例する**ので、赤が明るいほど絶対値が増える。

## 物理

Gr と Gb の隣接構成は RGB-IR の G(0,1) / G(1,0) と同じ:

| | 上/下 | 左/右 |
|---|---|---|
| Gr (0,1) | B, B | R, R |
| Gb (1,0) | R, R | B, B |

```
Gr = (w_L + w_R) * T_R + 2*w_y * T_B
Gb = (w_L + w_R) * T_B + 2*w_y * T_R
Gr - Gb = (w_L + w_R - 2*w_y) * (T_R - T_B)
```

**第 1 項は幾何**（CRA、F 値、CFA〜Si 距離）、**第 2 項は分光**（その波長での R と B の透過差）。
この積構造がすべてを説明する。

- CRA 0° ではカーネルが 4 回対称なので第 1 項がゼロ → **波長によらず厳密にゼロ**
- 550nm では R も B もほとんど透過しないので第 2 項がゼロ → **CRA によらずゼロ**
- 白色では第 2 項が波長積分で相殺 → 小さい

## 通常 RGGB Bayer の実測（3.0µm、f/1.8）

Gr/Gb アンバランス [%] = (Gr - Gb) / mean:

| 光源 | CRA 0° | CRA 30° |
|---|---|---|
| 6500K (400-1000nm) | -0.00 | -0.26 |
| 6500K (400-700nm) | -0.00 | -0.26 |
| 450nm | -0.04 | **-5.67** |
| 550nm | -0.00 | -0.02 |
| 650nm | +0.12 | **+14.79** |

## RGB-IR との比較（同一スタック・同一条件）

| 条件 | 通常 Bayer (Gr/Gb) | RGB-IR (6G 最大差) |
|---|---|---|
| CRA 0°, 450nm | 0.04% | **2.15%** |
| CRA 0°, 650nm | 0.12% | **5.50%** |
| CRA 0°, 白色 | 0.00% | 0.11% |
| CRA 30°, 450nm | 5.67% | 7.76% |
| CRA 30°, 650nm | 14.79% | 21.77% |
| CRA 30°, 白色 | 0.26% | 0.34% |

**RGB-IR 固有の追加分は「軸上でも消えない」こと。** 通常 Bayer は像高 0 で厳密にゼロなので
補正は「像高とともに増える成分」だけを扱えばよいが、RGB-IR では K 隣接の有無で軸上から
650nm・5.50% の差が残るため、**像高ゼロを基準にできない**。

### 「相対 % は大きいが信号が小さいので無害」は成立するか

**軸上では成立する**（ΔG/σ = 0.01〜0.03、ノイズの 30 分の 1 以下）。

**像高では成立しない**（ΔG/σ = 1.5〜3.6）。理由は 2 つ:

1. **ΔG の絶対値は信号レベルにほぼ依存しない。** 650nm 単色で 88e⁻、広帯域の赤物体でも 82e⁻。
   G 信号が 552 → 2820e⁻ と 5 倍増えても ΔG は変わらない。混色は R 画素から漏れてくる量で
   決まり、R 信号（= 10000e⁻ 固定）に比例するから。
   **分母の G だけが増えて分子は増えないので、相対 % は小さくなるが絶対値は減らない。**
2. **ショットノイズは √G でしか増えない。** G が 5 倍でも σ は 2.3 倍。

つまりこの現象の本質は「G 信号に対する割合」ではなく「**R 信号に対する漏れ量**」。

### 固定パターンであることの重み

- 空間相関を持つ周期構造は、ランダムノイズと違い**積分で消えない**。1.5σ でも空間平均で明確に見える
- デモザイクの方向推定を誤らせるため、振幅以上に迷路状構造として顕在化する
- 赤シーンでは CCM の R 行が G に大きな負係数を持つため、ΔG が R 出力に増幅されて伝播する

## 補正への含意（朗報）

ΔG の絶対値がシーンの分光にほぼ依らず **R 信号（および B 信号）に比例する**ので、補正則は

```
Gr - Gb = a(field) * R + b(field) * B
```

という**単純な線形形**になり、係数は像高だけの関数。分光依存の複雑な補正は不要で、
**像高テーブル 1 枚で扱える**。

RGB-IR では対象が 2 種 → 6 種に増え、像高ゼロのオフセット項が加わる。

## 但し書き

本モデルの幾何は全画素で同一なので、上の数値は**光学・CFA 混色に起因する分だけ**。
実機の Gr/Gb アンバランスには**レイアウト起因**の寄与（FD 共有時の配置差、画素トランジスタ
や配線の非対称、CFA 塗布膜厚差）が上乗せされる。これらは像高にも波長にも依存しない定数項
として現れるはずなので、**像高 0 で残る差がレイアウト成分の目安**になる。
モデル値と実測の差から切り分けられる。
