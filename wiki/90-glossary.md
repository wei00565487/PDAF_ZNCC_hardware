# 用語集

| 用語 | 説明 |
|---|---|
| **BSI** | 裏面照射。Si の裏面から光を入れ、前面（配線側）に PD を置く。本モデルは z=0 が裏面 |
| **BPM** | ビーム伝搬法。ここでは角スペクトル法による一方向のスカラー波動伝搬 |
| **角スペクトル法** | 場を平面波に分解し `exp(i*kz*dz)` を掛けて伝搬させる厳密解法（一方向） |
| **スプリットステップ** | 位相スクリーンと均質伝搬を交互に適用し、横方向屈折率分布を扱う BPM の形式 |
| **随伴法** | 収集確率を随伴問題として 1 回解き、任意の生成分布との内積でカーネルを得る手法 |
| **収集確率マップ u** | その点で生成したキャリアが対象 PD に収集される確率。`J = ∫G*u dV` |
| **混色カーネル K[o]** | 中心 CFA セルを通った光子のうち、オフセット `o` の PD で信号になった割合 |
| **DTI / BDTI / FDTI** | 深いトレンチ分離 / 裏面から掘る / 全深。本モデルでは光学的に吸収壁 |
| **低屈折率グリッド** | CFA セル間の低屈折率壁（n 約 1.25）。導波路として自セルに閉じ込める |
| **オンチップ IRCF** | R/G/B セル上のみに置く IR カット。K セル上には無い |
| **CRA** | 主光線角。像高に対応する入射角 |
| **瞳補正 / レンズシフト** | CRA 補正のためマイクロレンズを光の来る方向へずらすこと（符号に注意） |
| **F 値光束** | f/N レンズが届ける半角 `asin(1/2N)` の錐。フラットフィールドでは非干渉に強度加算 |
| **Gr / Gb** | Bayer の 2 つの緑。R 行の緑が Gr、B 行の緑が Gb |
| **Gr/Gb アンバランス** | 両者の感度差。デモザイク後に迷路状（maze / labyrinth）アーティファクトになる |
| **色純度** | 混色行列の対角成分。1 に近いほど純 |
| **CCM ノイズ利得** | 色補正行列の行ノルム。混色が大きいほど補正が強くなりノイズが増幅される |
| **RGB-IR** | R/G/B に IR 専用画素（K）を混ぜた配列。本 wiki では 4x4 周期 |
| **K 画素** | 可視カット / IR パスのセル。IR カットを載せない |
| **開口率 pd_fill** | PD フットプリント / ピッチ（線比） |
| **空乏層深さ pd_depth_um** | PD の収集領域の深さ。DTI とのオーバーラップが電気混色を決める |
| **Beer-Lambert** | `1 - exp(-alpha*t)` の吸収則。エネルギー保存検証の基準に使う |
| **van Cittert-Zernike** | 非干渉拡張光源の空間コヒーレンス定理。F 値光束を強度加算してよい根拠 |
